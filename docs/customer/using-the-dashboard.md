# Using the Dashboard

HyperCluster is organized by navigation groups (sidebar, desktop nav, or CLI command groups). Use search / command palette when available.

## Surfaces

| Need | Surface |
|------|--------|
| Fleet home | `dashboard` |
| Create cluster | `studio-hub` / `studio` |
| Day-2 cockpit | `cluster/*` |
| Deploy logs | `deploy` |
| CLI lifecycle | `hypercluster` CLI |

## Browse vs act

Inventory and status views are safe to explore. Mutating actions (deploy, migrate, sign, remediate) follow role gates and confirmation dialogs — review impact first.
