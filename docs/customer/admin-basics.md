# Admin Basics (HyperCluster)

## Ports / access

| Surface | Notes |
|---------|-------|
| Desktop | Hypercluster.app |
| CLI | `hypercluster` binary |
| SSH | port 22 to nodes |
| k3s API | :6443 (optional local tunnel :16443) |

## Auth

SSH keys in cluster.conf. Optional LLM keys for Ask Zeus. 30-day desktop trial on macOS.

## Install sketch

Follow the product README and deploy/Helm docs in the repository. Verify health endpoints or CLI status before opening the UI.
