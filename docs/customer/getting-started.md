Install the desktop app or use the CLI. There is no hosted web UI — Day-0/Day-2 runs from your workstation over SSH.

## 2. Sign in / authenticate

SSH keys in cluster.conf. Optional LLM keys for Ask Zeus. 30-day desktop trial on macOS.
